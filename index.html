Introduction

Hey, I’m Anthony. I’m a software engineer based in Michigan (Go Blue!) who likes building reliable systems and figuring out how all the pieces fit together. I currently work on backend infrastructure at Propio, a language services company whose software helps people communicate across languages.

Before Propio, I was a Software Development Engineer II at Amazon, working on backend systems for a high-traffic API platform used by selling partners and external developers. Most of my time went toward scalability, reliability, and making the platform easier to operate and build on.

Outside work, I build side projects that give me an excuse to learn new corners of web development, data engineering, and AI. You can find the ones I’m proudest of in Projects.

Travel is the other big through-line in my life. New cities, languages, food, and ways of living have shaped how I think—and given me plenty of ideas for things worth building.

I’m happiest working on useful things with thoughtful people. If that sounds like something we should talk about, you can browse my Resume or reach out through Contact.

Projects

A mix of live products, experiments, and older builds. Each one includes the story behind it, the tools I used, and a link or public repository when one exists.

Current

Resume Revamped

Resume Revamped is the project I keep coming back to: a live resume platform with company-inspired themes, AI-assisted tailoring and feedback, and near-1:1 browser-to-PDF rendering through Playwright. I built it end to end with Next.js, TypeScript, and Supabase; it now sees about 1.8k unique visitors each month.

A Pizza Michigan

A personal pizza spreadsheet got out of hand—in a good way—and became a food and location platform with 200,000+ entries. The public React app supports search, filters, reviews, and recommendations, while a multi-agent LLM pipeline on my home server handles scraping, enrichment, and validation.

DuoCalculator

A Duolingo course planner that estimates completion dates and required daily pacing. Course data is refreshed through an automated weekly scraping and validation pipeline covering nearly 300 courses.

Auction Notification Script

What began as a Python script on a Raspberry Pi became a full-stack app with profiles, authentication, and listing alerts across five auction sites.

Personal Website

This site is my long-running frontend playground. Its current version includes a deterministic background pipeline that combines location, season, local time, and live weather with generated city imagery.

College · Independent Projects

Mcity Video Processor

At Mcity, I built an AWS Batch pipeline that processed footage from autonomous shuttles. It sampled video frames, ran YOLO/Darknet object detection, and wrote labeled footage back to the source location. The image above shows the same model detecting objects in a photo from my first marathon.

Personal Website

This site started when I knew very little HTML, JavaScript, or CSS. I began with an existing template, learned by taking it apart, and gradually rebuilt it around my own style. The image compares an early version with the first major redesign.

Triple Boot Laptop

Mcity’s production workloads ran in Linux on AWS, so I added Ubuntu alongside Windows to keep local testing consistent. Then, because two operating systems apparently weren’t enough, I put macOS in a VM and completed the trio.

EECS Bullpen Website

College · Coursework

Secure File Server

The final project of my operating systems course—and my college career—was a secure, multithreaded network file server. It supported hierarchical files and directories and brought together socket programming, concurrency, and access control.

Virtual Memory Pager

My EECS 482 team implemented a kernel-level pager that managed process address spaces. It supported swap-backed and file-backed pages, page faults, and movement between virtual and physical memory.

Thread Library

My team built a user-level thread library for a single-CPU system, including threads, mutexes, and condition variables. The project was an early lesson in how quickly concurrency gets subtle.

Disk Scheduler

The first EECS 482 project was a multithreaded disk scheduler that accepted requests from multiple sources and serviced them safely. The output above shows the scheduler coordinating concurrent request streams.

Catanalyzer

For our computer vision final, we combined deep learning with classic vision techniques to read a Settlers of Catan board from live video and overlay useful game information. It was designed as both a teaching aid for new players and a tactical companion for experienced ones.

Diag Defender

Our embedded systems final was a small robot tasked with defending a block M. A front-mounted PixyCam detected colorful targets, while a second camera and ceiling-mounted IR LEDs helped the robot stay inside its arena.

Greple Search Engine

Six of us built a C/C++ search engine from the ground up—and spent plenty of late nights in the library doing it. Greple indexed more than three million documents; I focused on the crawler, query parser, and constraint solver.

Zookeeper

A zoo-themed algorithms project built around minimum spanning trees and traveling-salesperson heuristics. The scenarios included finding efficient routes for feeding animals and distributing water.

Log Manager

A command-line tool for exploring large collections of log entries. Users could filter by timestamp, category, or keyword, assemble excerpts, and reorder the result set.

Mine All Mine

A priority-queue project disguised as an escape from a rubble-filled mine. Each grid cell had a traversal cost, and the program found the path of least resistance while tracking statistics such as median rubble difficulty.

Letterman

A word-ladder solver that searched a custom dictionary for a path between two words. Each step could add, remove, or change one letter, and every intermediate result had to remain a valid word.

Piazza Post Classifier

A simple natural-language classifier trained on labeled Piazza posts. It learned associations between words and categories, then predicted labels for new, unseen posts.

RPN Calculator

A Reverse Polish Notation calculator backed by a stack implementation I wrote. Instead of 7 + 4 − 3, the same expression is entered as 7 4 + 3 −—awkward at first, oddly satisfying once it clicks.

Euchre Simulator

A full Euchre simulator—something of a rite of passage in Michigan’s EECS program—with configurable computer strategies and an option for a human player. Very Midwestern, very on brand.

Content-Aware Image Resizing

A seam-carving image resizer that identifies low-value pixel paths and removes them. It can change an image’s aspect ratio while preserving the parts that matter most.

Wind-Powered Turbine

My ENGR 100 team designed and fabricated a three-bladed Savonius wind turbine through several rounds of prototyping and review. We eventually tested it on the roof of the Space Research Building and generated enough power to light a bulb.
